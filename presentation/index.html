Built for the real workflow

Keys with guardrails

Manage A, B, C, and D independently with upload timestamps, per-set deletion, delete-all-keys, and strict 1–50 validation.

Single or batch

Evaluate one student or upload many PDFs. Names like Student_Name_RollNo_SetX.pdf detect identity and set automatically.

Rules that hold

Cutoff 40, blank answers count wrong, incomplete submissions keep their numeric score but always fail with a clear reason.

  • AcroForm-first extraction with text fallback
  • Duplicate roll numbers update in place
  • Excel export for all-time and batch results
  • Calibration/debug raw text and field dump
  • Independent student-results clearing
  • Per-file batch failure isolation
